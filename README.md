# 实体调试查看器（see）

Minecraft 1.21.11 / Fabric，客户端模组。默认对准实体按 **F8** 打开，在「选项 → 控制 → 按键绑定 → 实体调试查看器（See） → 检查实体」修改按键，Esc 关闭。安装 Controlling 时可以搜索「检查实体」或按分类搜索「See」。

- 单人及局域网主机：读取集成服务器的真实数据，以原版容器操作编辑物品。
- 多人及局域网客户端：只显示客户端可得的信息；整个界面只读，包括玩家物品栏。
- 界面主体采用原版普通单箱子的尺寸和玩家背包位置，顶部切换标签；检查实体默认打开「物品」页，其他信息页隐藏实体物品栏。
- 物品页第一行依次为头盔、胸甲、护腿、靴子；第二行为主手、副手；第三行为内部库存、搬运方块、身体装备、鞍等其他槽位。只显示实体实际存在的槽位，其他槽位超过九格时滚轮翻页，前两行和玩家背包固定。
- 信息页滚轮滚动数据。原始数据点击箭头展开，悬停看完整路径、类型和值，左右方向键横向滚动。
- 集成服务器中支持原版创造模式中键复制，保留物品名称、附魔、耐久等组件；生存模式不复制，多人只读模式不允许修改。
- 信息页仍可操作玩家背包；Shift 移动只在玩家背包和快捷栏间进行，不会转移到隐藏的实体槽位。
- 物品页 Shift 放入按显示顺序寻找槽位：头盔 → 胸甲 → 护腿 → 靴子 → 主手 → 副手 → 其他库存；保留原版同类物品优先合并、满格跳过的规则。
- 目标移除或卸载后保留最后数据并锁定编辑。关闭时鼠标上的物品由原版服务端归还，背包满时按原版规则掉落。
- 从箭矢、三叉戟等投射物取走其全部携带物品时移除该投射物，避免原版在重载时补回默认物品。
- 村民等内部库存按原版保存，重进世界时原版可能合并同类物品。
- 通过查看器放进村民主手的物品会保留在真实装备槽中，村民的交易展示和施肥展示不再覆盖或清空它；关闭界面、存档重载后仍生效，取走物品后恢复原版展示。村民 AI 保持运行。
- 末影人搬运方块显示在独立的“搬运方块”槽位，不与主手混淆；单人模式可用方块物品替换。为防止丢失物品组件，该槽位不接收非方块或带自定义组件的物品。

## 实体 NBT 编辑器

在 SEE 界面右上角点击「编辑 NBT」（多人只读时为「查看 NBT」），打开完整的实体 NBT 编辑器。界面和写回流程与 NBT Maker 的高级模式一致：

- 分类页：全部数据、基础、位置、生命、物品、行为、其他；未归类的字段（包括其他模组添加的）都在「其他」和「全部数据」中。
- 单击选择节点，单击 + / − 展开折叠，双击、右键或「编辑」打开值编辑器；「新增」「删除」「重命名」「复制节点」；搜索匹配节点名、类型和值；左右方向键横向滚动。
- 值编辑器默认 SNBT，可切换 String、布尔、数值、List、Compound、数组等类型。点击「载入编辑副本」只改变副本，**点击右上角「同步」才写入真实实体**。
- 「SNBT」菜单：复制副本、复制实体当前数据、粘贴导入、导入文件、导出文件（写入游戏目录 `see/exports/entity-时间.snbt`）。
- 「刷新」重新读取实体当前数据，同时保留尚未同步的修改。
- Esc / E 返回 SEE 界面，原来的标签页、库存翻页和容器保持不变；未同步的修改会丢弃。

写回规则：

- 只在单人或 LAN 房主的集成服务器中可编辑；多人和 LAN 房客严格只读，只能查看客户端可见的数据。
- 同步只把你修改过的字段合并到活的实体上，再交给原版 `Entity.load` 读取（与 `/data merge entity` 相同），因此坐标、速度、AI 记忆等每 tick 都在变化的字段不会被过期的副本覆盖。
- 编辑期间约每 4 tick 读取一次真实实体；你修改过的字段如果被游戏改变，会显示红色警告，但仍允许直接覆盖。
- 写入后读回实体：字段无法解析时整体还原并报错；被游戏调整的字段（例如生命值被上限截断）会在状态栏列出「请求值 / 实际值」，界面以实体实际数据刷新。
- 与原版 `/data` 一致，UUID 不可修改，玩家实体只读。
- 极端数值、超出世界边界的坐标、过大的速度、很深的嵌套或超大数据会在同步前要求确认。
- 如果修改改变了实体的物品槽位布局，SEE 原容器会显示「已失效」，关闭后重新打开即可。

开发构建：`./gradlew build`（JDK 21 或更高）。运行独立测试世界：`./gradlew runClientGameTest`。测试代码位于 `src/gametest`，不会打入发布 jar。

1.0.7 新增 NBT Maker 1.0.1 联动：在 SEE 中悬停物品，按 NBT Maker 的调试键（默认 X）打开物品数据编辑器。“同步”会写回真实实体物品，Esc 返回原 SEE 界面。两个模组仍可各自单独安装，联动用法见 [联动说明](SEE联动说明.md)。
